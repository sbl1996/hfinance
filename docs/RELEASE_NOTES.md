# Release Notes

## v1.0.2 - 2026-06-02

### Added

- 自动拉取任务支持从自选创建，不再仅限持仓标的。
- 自动拉取任务支持 `US_STOCK` 和 `CN_INDEX` 市场类型。
- 启动时自动迁移 `fetch_tasks` 与 `fetch_task_runs` 表约束，兼容旧库升级。

### Changed

- 任务创建/编辑弹窗改为合并展示持仓与自选，并按 `code + market` 去重。
- 任务列表和详情页补齐美股、指数市场标签显示。
- 已存在但不再出现在持仓/自选列表中的任务，编辑时仍保留当前任务值。

## v1.0.1 - 2026-05-29

### Added

- 自选标的新增 `指数` 类型，支持国内指数独立展示，不进入持仓统计。
- 支持中证红利低波等国内指数行情刷新，优先通过雪球页面抓取最新点位和涨跌幅，东方财富页面作为 fallback。
- `watchlist_items` 数据表支持 `CN_INDEX`，启动时自动迁移旧表约束。

### Changed

- 刷新全部改为按行情来源分组并行执行，同一来源内仍保持串行，降低总刷新耗时。
- 港股与国内指数的浏览器抓取归入同一个串行组，避免 `agent-browser` 页面切换互相干扰。
- 新增投资弹窗中，持仓模式只显示 A股、港股、基金；自选模式显示 A股、港股、基金、美股、指数。

### Fixed

- 修正并发刷新后交易日判断可能读到新写入缓存的问题。
- 修正持仓新增时可以选择不支持类型的问题。

## v1.0.0 - 2026-05-18

### Added

- 访客模式，支持非对称数据混淆。
- 持仓详情页面与走势图表。
- PWA 支持与应用图标。
- 持仓价格与数量的自动计算。
- 投资页“投资分布”明细卡片。
- 投资标的标题 Badge。
- 持仓“忽略”功能，支持将特定持仓排除在资产统计之外。
- 持仓市场类型标签（A股/港股/基金）。
- 持仓列表手动排序模式。
- 涨跌幅百分比标签。
- 实时计算当日盈亏 `daily_pnl_cny`。
- 基金历史净值全量导入服务。
- 使用 `agent-browser` 抓取港股数据。

### Changed

- 持仓卡片显示顺序。
- 基金净值抓取逻辑 `fetch_fund_nav`。
- SQLite 数据库模式从 WAL 切换回 `DELETE`。
- 部署脚本。
- 移动端显示尺寸适配。
- 持仓忽略后自动跳转回投资列表。
- 接口错误状态处理。

### Removed

- 移除盈亏日历和快照相关功能。
