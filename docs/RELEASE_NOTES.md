# Release Notes

## v1.0.6 - 2026-06-23

### Added

- “我的”页面新增“开启 VPN”开关，可直接查看和切换当前服务的外部抓取代理状态。
- 新增后端运行时代理状态接口 `GET /api/market/proxy-state` 与 `POST /api/market/proxy-state`。
- 新增后端单测，覆盖代理状态读写、权限控制，以及 `AKShare` / `agent-browser` 抓取链路的代理注入。

### Changed

- 所有后端外部 HTTP/HTTPS 抓取统一接入运行时代理层；当 VPN 开关开启时，会通过 `http://127.0.0.1:7890` 发起请求。
- 代理开关改为后端进程内全局状态，不落库、不写本地存储，服务重启后默认恢复关闭。
- 前端版本更新为 `v1.0.6`，后端版本更新为 `0.1.4`。

## v1.0.5 - 2026-06-23

### Changed

- 持仓详情页统一承接“全量导入净值”“忽略盈亏统计”“删除持仓”操作，编辑持仓弹窗仅保留表单字段和确认按钮。
- 自选详情页统一承接“全量导入净值”“删除自选”操作，编辑自选弹窗仅保留表单字段和确认按钮。
- 前端版本更新为 `v1.0.5`，可在登录页和个人页直接确认是否已加载新版本。

## v1.0.4 - 2026-06-23

### Added

- 自选 `指数` 详情页和编辑弹窗新增“全量导入净值”入口。
- 指数全量导入支持在导入前临时选择 `深交所 / 上交所 / 中信指数` 前缀类型。
- 新增 AkShare 指数历史导入链路，使用 `stock_zh_index_daily_em` 的 `close` 列写入价格缓存。
- 新增后端单测，覆盖指数导入 symbol 生成与 `date / close` 列解析。

### Changed

- 前端版本更新为 `v1.0.4`，可在登录页和个人页直接确认是否已加载新版本。
- 后端版本更新为 `0.1.3`。

## v1.0.3 - 2026-06-16

### Added

- 基金持仓与基金自选新增币种配置，支持 `人民币 / 港币 / 美元`，默认人民币。
- 启动时自动为 `holdings` 与 `watchlist_items` 数据表补齐 `currency` 列，兼容旧库升级。
- 新增 `USDCNY` 汇率缓存链路，后续美元基金估值可直接复用。

### Changed

- 基金净值刷新、单标的刷新与全量历史导入会按基金配置币种写入价格缓存，不再固定按人民币处理。
- 持仓市值、累计盈亏、当日盈亏、Dashboard 汇总与持仓详情收益曲线统一改为按价格币种折算成人民币。
- 手动刷新外汇时改为单次抓取同时更新 `HKDCNY` 和 `USDCNY`，减少 `ak.fx_spot_quote()` 调用次数。
- 新增投资、编辑持仓、编辑自选表单在基金场景下显示币种选择；持仓列表与详情页补齐美元/港币价格展示。

### Fixed

- 修正自选列表在缺少前一日缓存价格时，涨跌幅 fallback 可能为空的问题。
- 修正“刷新基金”不会同步刷新美元/港币兑人民币汇率，导致外币基金被按 `1.0` 汇率估值的问题。
- 修正美元基金详情页在缺少逐日汇率缓存时，历史曲线和收益率按原币直接与人民币成本比较的问题。
- 限制同一基金代码在持仓/自选中只能保存一种币种配置，避免价格缓存口径冲突。

## v1.0.2 - 2026-06-02

### Added

- 自动拉取任务支持从自选创建，不再仅限持仓标的。
- 自动拉取任务支持 `US_STOCK` 和 `CN_INDEX` 市场类型。
- 启动时自动迁移 `fetch_tasks` 与 `fetch_task_runs` 表约束，兼容旧库升级。

### Changed

- 任务创建/编辑弹窗改为合并展示持仓与自选，并按 `code + market` 去重。
- 任务列表和详情页补齐美股、指数市场标签显示。
- 已存在但不再出现在持仓/自选列表中的任务，编辑时仍保留当前任务值。

## v1.0.1 - 2026-05-29

### Added

- 自选标的新增 `指数` 类型，支持国内指数独立展示，不进入持仓统计。
- 支持中证红利低波等国内指数行情刷新，优先通过雪球页面抓取最新点位和涨跌幅，东方财富页面作为 fallback。
- `watchlist_items` 数据表支持 `CN_INDEX`，启动时自动迁移旧表约束。

### Changed

- 刷新全部改为按行情来源分组并行执行，同一来源内仍保持串行，降低总刷新耗时。
- 港股与国内指数的浏览器抓取归入同一个串行组，避免 `agent-browser` 页面切换互相干扰。
- 新增投资弹窗中，持仓模式只显示 A股、港股、基金；自选模式显示 A股、港股、基金、美股、指数。

### Fixed

- 修正并发刷新后交易日判断可能读到新写入缓存的问题。
- 修正持仓新增时可以选择不支持类型的问题。

## v1.0.0 - 2026-05-18

### Added

- 访客模式，支持非对称数据混淆。
- 持仓详情页面与走势图表。
- PWA 支持与应用图标。
- 持仓价格与数量的自动计算。
- 投资页“投资分布”明细卡片。
- 投资标的标题 Badge。
- 持仓“忽略”功能，支持将特定持仓排除在资产统计之外。
- 持仓市场类型标签（A股/港股/基金）。
- 持仓列表手动排序模式。
- 涨跌幅百分比标签。
- 实时计算当日盈亏 `daily_pnl_cny`。
- 基金历史净值全量导入服务。
- 使用 `agent-browser` 抓取港股数据。

### Changed

- 持仓卡片显示顺序。
- 基金净值抓取逻辑 `fetch_fund_nav`。
- SQLite 数据库模式从 WAL 切换回 `DELETE`。
- 部署脚本。
- 移动端显示尺寸适配。
- 持仓忽略后自动跳转回投资列表。
- 接口错误状态处理。

### Removed

- 移除盈亏日历和快照相关功能。
